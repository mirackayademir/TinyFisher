## Arşiv / alternatif görseller

- Eski Fener Balığı SVG görseli `generation/fish/fener_baligi.svg` altında arşiv olarak korunuyor; aktif oyun görseli `generation/fish/fener_baligi_yeni.webp`.
- Kılıç Balığı yeniden aktif tür olarak oyuna eklendi; kanonik görsel `generation/fish/kilic_baligi.webp`.
- Bozuk legacy WebP kopyaları kaldırıldı.
- Barakuda, Müren, Vatoz, Deniz Şeytanı, Kalamar ve Köpekbalığı WebP dosyaları sağlam runtime verisinden yeniden oluşturuldu.

Eski fallback ve alternatif formatlar `generation/archive/` altında tutulur. Bunlar karşılaştırma ve geri dönüş içindir; kanonik oyun assetleri değildir.

## Runtime encoded kaynaklar

Toplam **127** adet base64/parçalı runtime asset kaynağı `generation/runtime_encoded/` altına kopyalandı. Balıkların exact-art parçaları ve canyon runtime parçaları burada korunuyor.

## Canyon notu

Kodun tercih ettiği tek parça `assets/environment/terrain/canyon_hq.png` / `canyon_hq.webp` dosyası repoda fiziksel tek parça görsel olarak bulunmuyor. Mevcut canyon runtime parçalarının tamamı `generation/runtime_encoded/environment/terrain/` altında korundu. Tek parça HQ kaynak tekrar mevcut olduğunda kanonik hedef `generation/environment/terrain/canyon_hq.png` olacak.

## İsimlendirme standardı

- Küçük harf + snake_case.
- `_TEMP` ekleri generation kopyalarında kaldırılır.
- Eski / alternatif görseller `generation/archive/` altında tutulur.
- Base64/parçalı runtime verileri `generation/runtime_encoded/` altında tutulur.
- Oyunun kullanacağı yeni görseller mümkün olduğunca doğrudan `generation/` yollarından çağrılır.
