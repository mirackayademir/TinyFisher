# TinyFisher Environment Assets

Bu paket 2026-09-09 / 2026-09-10 görsel üretim turunda hazırlanan 36 environment assetini içerir.

Klasörler:
- surface: gökyüzü, güneş, ufuk, deniz yüzeyi, dalgalar, köpük, ışınlar
- shallow: 0-20 m
- open_blue: 20-50 m
- deep_sea: 50-80 m
- abyss: 80-100 m
- leviathan: 92-100 m özel çevre

Dosya adında _TEMP bulunan görseller kullanıcı tarafından "idare eder/geçici" olarak işaretlenmiştir.
Bunlar final asset kabul edilmemeli; entegrasyonda kullanılabilir ama polish turunda yeniden değerlendirilecek.
